# Toreca Vault

スマートフォン優先のトレーディングカード管理Webアプリです。データはブラウザのLocalStorageだけに保存され、サーバーには送信されません。

## 機能

- 抽選、購入・支出、未開封BOX、バラパック、カード、開封、売却の記録
- 資産集計と店舗別実績
- 更新可能な商品マスター
- JSONバックアップ／復元
- 旧アプリJSONの追加インポート（変換層は `js/schema.js`）
- オフライン利用対応
- 購入時の在庫追加、売却時の在庫減算を自動連動
- BOX開封時にBOX在庫を減らし、残したバラパックを取得原価0円で登録

## ローカル確認

```sh
npm test
python3 -m http.server 4173
```

`http://localhost:4173` を開いてください。

## データ移行

バックアップ形式は `schemaVersion` を持ちます。旧アプリ固有のキー対応は `legacyMap` に追加でき、保存モデルとUIを変更せず移行処理だけ拡張できます。
