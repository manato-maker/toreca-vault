# シングルカード：買取相場の参照・ステージング反映手順

目的：在庫カテゴリ「カード」を購入原価や販売価格と混ぜず、最新の買取価格で参考評価する。まず正本を**読む**。現在の出典データがなければ買取額は未取得のまま。数値を創作しない。

## 1. 在庫と商品識別

認証済みCloud Shellから `node cloud/scripts/staging-promo-card-market.js --inspect` は状態確認のみ。オーナーが承認した個別在庫原価の補正と、カード在庫のテキスト抽出は `--apply`。限定的な補正対象名・元原価・新原価・数量は、公開GitHubに置かず `TV_STAGING_COST_*` 環境変数で渡す。

個人用ファイル `~/toreca-single-cards-for-market.txt` にカード名・数量・カード番号（記録済みの場合のみ）・レアリティ・状態を出力。ロットID・仕入店舗・原価・取引記録は出力しない。

## 2. 相場調査

第一候補：<https://www.cardrush-pokemon.jp/page/40>（カードラッシュ公式の**買取リスト**）。
第二候補：<https://altema.jp/pokemoncard/>（ポケカチの**買取価格**欄）。アルテマ掲載の買取額はカードラッシュ等の参照値を含むため、同一値を別店舗2件として二重計上しない。

各カードをカード名だけではなく **カード番号 / 収録弾 / レアリティ / 型番 / 状態** で照合。買取価格と販売価格を取り違えない。出典URLと掲載日（またはデータ最終更新日時）を必須にし、取得日ではなく**価格掲載日時**を使って有効性を判断する。直近168時間を超える価格は参考評価に使用しない。情報のない項目は「未確認」、同名異版や曖昧なカードは「要確認」。

ポケモンカード以外は対象外。価格が更新されていても、出典日時や対応カード番号が不明な場合は保留。カードラッシュ商品販売ページの価格は売価であり買取相場ではない。

## 3. ステージングへの反映

現段階では、まず正本のカード一覧が抽出され、正しいカードとサイトの買取価格が照合できることを確認する。外部サイトの掲載価格を自動的に `verified` として書き込む機能は未実装。次の作業は一致したカードについて、元URL・買取価格・掲載日時・種別・状態を保存できる専用の**証拠付き・重複防止・読取検証付き取込**を追加すること。

アプリの原価や購入・売却履歴を価格調査で書き換えない。旧V2や本番に書き込まない。認証や公開Web経由の無制限書込みを作らない。
